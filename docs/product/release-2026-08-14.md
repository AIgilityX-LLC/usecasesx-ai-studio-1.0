# Release 2026-08-14 — Lite + Pro Founding Access

**Product**: UseCasesX™ — Global AI Use Case Repository, AI Opportunity Map and AI Use Case Studio™.
**Launch date**: 14 August 2026.
**Principle**: launch a *complete customer journey*, not the complete Enterprise catalogue.

---

## 1. Editions at launch

| Edition | Status on 14 Aug 2026 | Access | Notes |
|---|---|---|---|
| **Lite** | GA | Public, unauthenticated | Discovery of the repository and Opportunity Map. |
| **Pro Founding Access** | GA | Registered professional users | Complimentary through **31 December 2026**, subject to fair-use limits. |
| **Enterprise** | Architecture-ready, not GA | Paid Enterprise Design Partner engagements only | Same codebase; gated by entitlements. No public claim that Enterprise features are live. |

---

## 2. In-scope journeys (must work end-to-end)

The full core journey ships on Day 1:

**Discover → Capture Opportunity → Design → Score → Prioritize → Portfolio → Roadmap → Export → Advisory.**

Concretely at launch:

- Discovery of the global repository (Lite + Pro).
- Opportunity capture into a workspace-scoped Studio.
- Use-case design via the Blueprint builder.
- Feasibility scoring (5-pillar) and Quick Wins.
- Prioritization + Portfolio views.
- Basic Roadmap export from Portfolio.
- Blueprint/report export (PDF + Word).
- Advisory handoff surfaces (SARPI, C3G Governance, AdvisorX intake).

---

## 3. Deferred to post-launch

Explicitly not GA on 14 Aug 2026:

- Full 12-deliverable Enterprise handover package (structured generators for #4/#6/#7/#8/#10/#11/#12 remain roadmap; hub scaffolding is present but not marketed as complete).
- Advanced Enterprise roles beyond Owner/Admin/Contributor/Viewer/Facilitator.
- Multi-org, sovereign local deployment, decision provenance UI, auditor views.
- Custom governance packs and advanced audit exports.
- Deep API Integration surfaces beyond the current marketing/config page.

These remain in-codebase behind entitlements and feature flags; no UI may imply they are live.

---

## 4. Roles at launch

- **Workspace Owner** — full workspace admin, billing where applicable.
- **Workspace Admin** — manage members, data, exports.
- **Contributor** — create/edit use cases, blueprints, scores.
- **Viewer** — read-only access.
- **Facilitator** — workshop-mode access for advisory sessions.

Advanced Enterprise roles are reserved and gated.

## 5. Success metrics

Instrument (using existing `module-analytics` / `usecasex.tracking`), review weekly:

**Activation**
- % of signed-in users who complete Discover → Capture Opportunity within 7 days.
- Median time-to-first Blueprint.

**Depth**
- % of Pro users reaching Score → Prioritize.
- Portfolio views per active workspace / week.

**Export & handoff**
- Blueprint exports per active workspace / week.
- Advisory intake submissions (SARPI, C3G, AdvisorX).

**Reliability**
- P95 route load < 2 s on the core journey.
- Zero P1 RLS or auth regressions.

**Founding Access hygiene**
- Founding-member cohort size and retention through 31 Dec 2026.
- Fair-use threshold breaches.

## 6. Launch acceptance gates

Ship only when all of these hold:

1. `bun run build`, `bun run lint`, `tsgo` all green.
2. `bun run test:e2e`, `bun run test:rls`, `bun run test:navbar`, `bun run test:mobile` green.
3. `bun run check:nav-integrity` and `bun run check:compare` green.
4. Every route has a unique branded `head()` — no "Lovable App" defaults.
5. No dead CTAs, no placeholder production records, no fake metrics.
6. `docs/PRE_BETA_RELEASE_CHECKLIST.md` fully checked.
7. Security scan clean; RLS enforced on every `public` table.
8. Rollback plan documented per change set.
