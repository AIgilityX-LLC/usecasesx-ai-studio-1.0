## Nav-integrity enforcement

Changes to `SiteShell.tsx` or `AppSidebar.tsx` must pass:

```
bun run check:nav-integrity
bun run test:navbar
```

Redirect additions must also be reflected in `src/lib/nav-integrity.ts` (`EXPECTED_REDIRECTS`) or the CI will fail.
